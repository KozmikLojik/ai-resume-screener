# AI Resume Screener  
**NLP + BERT + FastAPI + Streamlit**  
*End-to-end AI system to match resumes with job descriptions*

Live Demo: [https://ai-resume-screener.onrender.com](https://ai-resume-screener.onrender.com)  
API Docs: `/docs` (after running API)

---

## Features
- PDF Resume Parsing
- BERT Semantic Matching
- FastAPI Backend
- Streamlit Web App
- Deployable (Render, Docker)

---

## Quick Start

```bash
# Clone
git clone https://github.com/yourusername/ai-resume-screener.git
cd ai-resume-screener

# Install
pip install -r requirements.txt

# Run API
python run_api.py

# In another terminal, run app
streamlit run app/streamlit_app.py"# ai-resume-screener"
